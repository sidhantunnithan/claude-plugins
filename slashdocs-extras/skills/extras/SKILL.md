# slashdocs extras

Use these together with the stock `slashdocs` skill.

In docs, prefer diagrams (Mermaid or inline SVG, text kept selectable) over walls of text for anything complex: architecture, flows, sequences, comparisons.

Read the reference that matches the task:

- `references/review-format.md`: handling a review round: reading comments, in-page answer blocks, OPEN items, contents sidebar, closing out.
- `references/attachments.md`: linking large files (archives, logs, datasets, recordings, binaries) with `slashdocs-attach` instead of embedding them.
